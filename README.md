# Korepetycje online — strona jednoczęściowa

Landing page dla mojej własnej praktyki korepetycyjnej (angielski + matematyka, klasy 4–8 i liceum,
matura, egzamin ósmoklasisty) — zaprojektowana i wyprodukowana przeze mnie od podstaw (struktura,
teksty, dobór treści pod konwersję, SEO, decyzje designerskie), z implementacją kodu przez Gemini.

🔗 **Live:** [ola-korepetycje.pl](https://ola-korepetycje.pl)
<img width="1165" height="804" alt="image" src="https://github.com/user-attachments/assets/60aab40b-cd7d-4730-8ea9-7ba10fd93dfc" />


**Dlaczego ten projekt:** potrzebowałam realnej wizytówki pod własną markę tutoringową. Skupiłam się
na tym, żeby strona faktycznie sprzedawała — struktura sekcji, copy, social proof, SEO i dostępność —
a implementację kodu poprowadziłam z Gemini, samodzielnie podejmując wszystkie decyzje produktowe
i weryfikując efekt.

**Co pokazuje ten projekt:**
- Kompletny, wdrożony produkt (nie tylko tutorial/ćwiczenie) — działa produkcyjnie i przyjmuje realny ruch
- Umiejętność prowadzenia projektu end-to-end z AI jako narzędziem implementacyjnym: definiowanie wymagań, iteracja, ocena i poprawki
- Konfigurowalna architektura — cała treść i dane wydzielone do jednego pliku (`site.ts`)
- Dbałość o SEO/dostępność/performance, nie tylko o UI

**Stack:** Next.js 16 · React 19 · TypeScript · Tailwind CSS v4 · Framer Motion
